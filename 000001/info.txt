MIS CUOTAS (frontend, por usuario logueado)
- Cada usuario que se registra (frontend/site/signup, ya venia con Yii2) tiene sus propias cuotas, totalmente separadas de las de otros usuarios.
- Tabla: prestamo (migracion console/migrations/m260924_171125_create_prestamo_table.php), con columna user_id (FK a user, ON DELETE CASCADE: si se borra un usuario se borran sus cuotas).
- Modelo: common/models/Prestamo.php (misma logica de calculo que tenia cuenta-cuotas/functions.php: detalle de cuotas pagadas/pendientes, calendario mensual de 6 meses atras + 12 adelante).
- Controlador: frontend/controllers/PrestamoController.php (accesible solo logueado). Cada accion filtra siempre por user_id = usuario actual; si alguien intenta editar/borrar una cuota ajena por URL, devuelve 404 (probado).
- Vistas: frontend/views/prestamo/ (index = dashboard con alta+listado+calendario, update = editar).
- Link "Mis cuotas" agregado al menu del layout frontend/views/layouts/main.php (visible solo logueado).
- Probado extremo a extremo: dos usuarios de prueba, cada uno solo vio/pudo tocar sus propias cuotas; se limpiaron esos datos de prueba al terminar.
- 13 cuotas reales migradas desde cuenta_cuotas.prestamos al usuario "david" (id 5).

ESTILOS Y RESPONSIVE
- CSS propio: frontend/web/css/cuotas.css (registrado en frontend/assets/AppAsset.php). Usa variables de Bootstrap (--bs-*) para que quede sincronizado con el modo claro/oscuro real de Bootstrap.
- Modo oscuro: frontend/views/layouts/main.php tiene un script que detecta prefers-color-scheme del sistema y pone data-bs-theme="dark" en el <html>, para que Bootstrap cambie todo de forma coherente (evita texto oscuro sobre fondo oscuro).
- Home: frontend/config/main.php tiene defaultRoute y homeUrl apuntando a prestamo/index (se saco la pagina de bienvenida default de Yii2). SiteController::actionIndex hace goHome().
- Menu del frontend simplificado: solo "Mis cuotas" (logueado) o "Signup" (invitado).
